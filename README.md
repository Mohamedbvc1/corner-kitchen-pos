# The Corner Kitchen – Restaurant POS

Final group project for SODV1251 at Bow Valley College.
A point-of-sale system for a small fast-food restaurant:
customers order online, and staff take walk-in orders,
run the kitchen board, and manage the menu, inventory and staff.

## Who does what
We split the work half and half and may swap issues as we go.

- **Mohamed:** server, database, seed data, APIs, sign-in and
  password reset, emails, card payment, deployment
- **Abdel:** screen pages – menu, cart, order status,
  Sales page, orders board, and manager screens
- Once the server is done, we work on the remaining pages together.

## Tech
Node.js, Express, MongoDB (Mongoose), HTML, CSS, JavaScript
